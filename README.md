## 🇪🇸 Español

# Reloj Digital & Temporizador Minimalista

Una aplicación web de reloj analógico/digital minimalista diseñada con **HTML5**, **Tailwind CSS** y **JavaScript (Vanilla)**. Reproduce la estética retro de pantallas de cristal líquido / LED con tipografía digital, brillo glow y sintetizador de sonido retro mediante la Web Audio API.

### 🚀 Características

* **Vista Principal (Ajustes):** Selección de modo (*Timer* o *Countdown*), campo numérico para horas/minutos/segundos y un interruptor de color.

* **Vista Secundaria (Reloj):** Pantalla limpia sin distractores, enfocada únicamente en el tiempo.

* **Normalización Automática de Tiempo:** Conversión inteligente de valores (ej. ingresar 90 segundos los transforma automáticamente a 1 minuto y 30 segundos).

* **Visibilidad Dinámica en Countdown:** Si solo configuras segundos, las secciones de horas y minutos se ocultan automáticamente.

* **Personalización de Color:** Cambia al instante entre Verde Hex (`#00ff00`) y Rojo Hex (`#ff0000`).

* **Alarma Retro Sintetizada:** Emisión de un tono *bip-bip* de 880Hz generado por Web Audio API al finalizar una cuenta regresiva.

* **Diseño Ultra Minimalista:** Fondo negro mate con fuente estilo digital (`Share Tech Mono`) y efectos de iluminación (*text-shadow glow*).

### 🛠️ Tecnologías Utilizadas

* **HTML5**

* **Tailwind CSS (v3 via CDN)**

* **JavaScript ES6+**

* **Web Audio API**

## 🇬🇧 English

# Minimalist Digital Clock & Timer

A minimalist analog/digital clock web application designed with **HTML5**, **Tailwind CSS**, and **JavaScript (Vanilla)**. It replicates the retro aesthetic of LCD/LED screens featuring digital typography, a glow effect, and a retro sound synthesizer powered by the Web Audio API.

### 🚀 Features

* **Main View (Settings):** Mode selection (*Timer* or *Countdown*), numeric fields for hours/minutes/seconds, and a color toggle switch.

* **Secondary View (Clock):** A clean, distraction-free screen focused entirely on the time.

* **Automatic Time Normalization:** Smart value conversion (e.g., entering 90 seconds automatically transforms it into 1 minute and 30 seconds).

* **Dynamic Visibility in Countdown:** If you only set seconds, the hours and minutes sections are automatically hidden.

* **Color Customization:** Instantly switch between Hex Green (`#00ff00`) and Hex Red (`#ff0000`).

* **Synthesized Retro Alarm:** Emits an 880Hz *beep-beep* tone generated by the Web Audio API when a countdown finishes.

* **Ultra-Minimalist Design:** Matte black background with a digital-style font (`Share Tech Mono`) and lighting effects (*text-shadow glow*).

### 🛠️ Technologies Used

* **HTML5**

* **Tailwind CSS (v3 via CDN)**

* **JavaScript ES6+**

* **Web Audio API**
